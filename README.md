# imdb-movies-sql-capstone
SQL capstone project analyzing IMDb movie ratings, genres, and revenue trends
## 📂 Project Files
* 📝 [View SQL Queries (imdb_movies_queries.sql)](./imdb_movies_queries.sql)

## 🔍 Key Focus Areas & SQL Techniques
* *Data Filtering & Aggregation:* Analyzing top-rated films, release year trends, and revenue metrics using GROUP BY, HAVING, and aggregate functions.
* *Ranking & Comparisons:* Identifying top-performing genres, actors, and directors using ORDER BY, LIMIT, and window functions/subqueries.
